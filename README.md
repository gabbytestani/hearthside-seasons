# Hearthside Seasons

A cozy, Yule-log-style website of animated holiday villages and indoor rooms. The scene changes automatically with the calendar, and each holiday has an indoor and outdoor view, ambient sound, and its own page effects.

Created by Gabriella Testani.

## Run it

Open `index.html` in a browser. No build step or dependencies; fonts load from Google Fonts.

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
